# Market watchlist

Always prefer exact values and short-term changes.

## Core numeric indicators
- Brent crude: price, % change, session timestamp/source.
- WTI crude and Brent-WTI spread.
- OVX or oil volatility proxy from CBOE/Barchart/market reports.
- VIX and MOVE exact value or last close.
- Gold spot/front-month and % change.
- DXY exact value and % change.
- FX: USD/ILS, USD/TRY, EUR/USD, USD/JPY, USD/CHF.
- U.S. Treasury 2Y, 10Y, 30Y; credit spreads if available.
- Defense equities: LMT, RTX, NOC, GD, ESLT, Rheinmetall; include % move if available.
- Airlines/tourism/shipping: airline basket or selected tickers; tanker/shipping equities/rates where public.
- Regional equities: S&P 500, Nasdaq, Dow, STOXX Europe, DAX/CAC/FTSE, Nikkei/Hang Seng, TASE/TA-35 if readable.
- Crypto: BTC, ETH, USDT dominance/premium if public.
- Polymarket Iran: probability, volume, liquidity, 24h change for relevant markets.

## Interpretation rules
- Oil up + OVX up + gold up + DXY up + equities down is stronger than any one signal.
- Airspace/NOTAM + military logistics + maritime warnings outweigh calm equities.
- Equities resilient while oil/shipping stressed suggests crisis containment pricing, not risk absence.
- Prediction markets are useful for sentiment but can be noisy, thin, or affected by insider/whale behavior.
